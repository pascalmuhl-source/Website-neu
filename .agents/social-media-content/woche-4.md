## Montag — LinkedIn / Instagram / Facebook
**Topic**: Was Anwälte/Versicherungen in 5 Sekunden auf Ihrer Seite sehen müssen
**Pillar**: Website-Wirkung & Pain-Punkte (Supporting) · **Format**: Standalone (LI), Caption (IG), Standalone (FB)

### LinkedIn
```
Anwälte und Versicherungen suchen anders nach Sachverständigen als
Privatpersonen. Sie haben wenig Zeit und einen konkreten Fall vor sich.

Was diese Zielgruppe in den ersten 5 Sekunden auf Ihrer Seite sehen muss:

→ Das exakte Fachgebiet — nicht "technische Gutachten", sondern konkret
→ Einen Hinweis auf Erfahrung mit vergleichbaren Fällen
→ Einen Weg zur Kontaktaufnahme, der keine Recherche erfordert

Was in dieser kurzen Zeit nicht zählt: Ein aufwändiges Design, lange
Über-mich-Texte, oder eine beeindruckende Startseiten-Animation.

Auftraggeber mit wenig Zeit wollen eine schnelle, klare Antwort auf eine
Frage: "Ist das die richtige Person für meinen Fall?"

Beantwortet Ihre Startseite diese Frage in 5 Sekunden?

#Sachverständige #Anwälte #Webdesign
```

**Pillar**: Einblicke ins Handwerk (Supporting) · **Format**: Standalone (LI), Caption (IG), Standalone (FB)

### LinkedIn
```

Erinnerung rufen sollte:

Ich hatte einen ersten Entwurf für eine Startseite fertig — sauber
strukturiert, aus meiner Sicht klar. Beim Gespräch mit dem Kunden kam dann

korrekt", sondern "versteht das jemand ohne Vorwissen, unter Zeitdruck".

#Sachverständige #Webdesign #Learning
```

## Mittwoch — LinkedIn / Instagram / Facebook
**Topic**: Warum „wirkt veraltet" bei Gutachten doppelt schadet
**Pillar**: Website-Wirkung & Pain-Punkte (Ausnahme-Slot, Supporting) · **Format**: Standalone (LI), Caption (IG), Standalone (FB)

### LinkedIn
```
Bei den meisten Dienstleistungen bedeutet eine veraltete Website: verpasste
Chance, aber verzeihlich.

Bei Sachverständigen bedeutet es etwas anderes.

Ein Gutachten lebt von Sorgfalt, Aktualität und Genauigkeit. Wirkt die
Website veraltet, entsteht unbewusst der Gedanke: "Ist die fachliche Arbeit
vielleicht genauso wenig gepflegt wie die Website?"

Das ist nicht fair — die meisten veralteten Websites gehören zu
Sachverständigen, die exzellente Arbeit leisten. Aber der erste Eindruck
entscheidet, bevor jemand die Chance bekommt, das Gegenteil zu beweisen.

Eine aktuelle, gepflegte Website ist bei Ihnen kein Nice-to-have. Sie ist
ein stilles Argument für die Sorgfalt Ihrer eigentlichen Arbeit.

#Sachverständige #Webdesign #Vertrauen
```

### Instagram
```
Bei den meisten Branchen: veraltete Website = verpasste Chance.

Bei Sachverständigen: veraltete Website = unbewusster Zweifel an der
fachlichen Sorgfalt.

Nicht fair. Aber genau so wird entschieden.

#sachverständiger #webdesign #vertrauen
```

### Facebook

```
Nicht fair, aber genau so wird oft entschieden.

#Sachverständige #Webdesign
```

## Donnerstag — LinkedIn / Instagram / Facebook
**Topic**: Kurzer Tipp zu Kontaktformularen & Erreichbarkeit
**Pillar**: Praktische Tipps für Einzelkämpfer (Supporting) · **Format**: Standalone (LI), Caption (IG), Standalone (FB)

### LinkedIn
```
Ein kurzer, konkreter Tipp für Ihr Kontaktformular:

Weniger Pflichtfelder als Sie denken. Name, E-Mail, Nachricht reichen fast
immer. Jedes zusätzliche Pflichtfeld ist eine Chance, dass jemand unter
Zeitdruck abbricht.

Ein optionales Auswahlfeld ("Worum geht's?") kann sinnvoll sein, um Anfragen
grob einzuordnen — aber nur, wenn es nicht verpflichtend ist.

Genauso wichtig: Telefonnummer und E-Mail-Adresse zusätzlich sichtbar
platzieren, nicht nur im Formular versteckt. Manche Auftraggeber wollen
direkt anrufen, nicht warten.

Und: ein kurzer Hinweis, wofür die Daten verwendet werden, direkt am
Formular — nicht nur in der Datenschutzerklärung, die kaum jemand vorher
liest.

Wie viele Pflichtfelder hat Ihr eigenes Kontaktformular gerade?

#Sachverständige #Webdesign #Tipp
```

### Instagram
```
Kurzer Tipp fürs Kontaktformular:

→ Nur Name, E-Mail, Nachricht als Pflicht
→ Telefonnummer zusätzlich sichtbar, nicht nur im Formular
→ Kurzer Datenschutz-Hinweis direkt am Formular

Weniger Hürden = mehr Anfragen.

#sachverständiger #webdesign #tipp #kontaktformular
```

### Facebook

```
Weniger Hürden bedeuten mehr Anfragen.

#Sachverständige #Webdesign
```
