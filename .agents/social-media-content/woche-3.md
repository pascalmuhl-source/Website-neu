## Montag — LinkedIn / Instagram / Facebook
**Topic**: Checkliste — Ist Ihre Website auf dem Handy wirklich nutzbar?
**Pillar**: Website-Wirkung & Pain-Punkte (Supporting) · **Format**: Standalone (LI), Caption (IG), Standalone (FB)

### LinkedIn
```
Die meisten Anfragen bei Sachverständigen kommen heute über das Smartphone —
oft direkt nach einem Schadensfall, unterwegs, unter Zeitdruck.

Eine kurze Selbstprüfung, 2 Minuten:

→ Öffnen Sie Ihre Website auf dem Handy, nicht am Desktop.
→ Müssen Sie zoomen, um Text zu lesen?
→ Lässt sich die Telefonnummer mit einem Klick anrufen?
→ Braucht das Kontaktformular mehr als 3 Felder?
→ Lädt die Seite spürbar langsam?

Jedes "Ja" auf zoomen/langsam/zu viele Felder ist ein Punkt, an dem jemand
unter Zeitdruck aufgibt und woanders anruft.

Wie schneidet Ihre eigene Seite bei diesem Test ab?

#Sachverständige #Mobile #Webdesign
```

## Dienstag — LinkedIn / Instagram / Facebook
**Topic**: Ein Blick hinter die Kulissen eines Projekts
**Pillar**: Einblicke ins Handwerk (Supporting) · **Format**: Standalone (LI), Caption/Story (IG), Standalone (FB)

### LinkedIn
```
Was in einem Website-Projekt für einen Sachverständigen tatsächlich passiert,
bevor die erste Zeile Text geschrieben wird:

Zuerst geht es nicht um Farben oder Schriftarten. Es geht um eine Frage:
Wie erklärt diese Person ihr Fachgebiet, wenn sie es einem Laien beschreibt?

Diese Antwort — meist ein einfacher, konkreter Satz — wird zur Grundlage für
die ganze Seite. Struktur, Wortwahl, sogar die Reihenfolge der Inhalte
entstehen daraus.

Erst danach kommt Design. Nicht umgekehrt.

Der häufigste Fehler bei Baukasten-Websites: Es wird mit der Vorlage
angefangen, nicht mit dieser einen Frage.

#Sachverständige #Prozess #Webdesign
```

## Mittwoch — LinkedIn / Instagram / Facebook
**Topic**: Ein Mythos über Cookie-Banner, den viele glauben
**Pillar**: Datenschutz & Vertrauen (Supporting) · **Format**: Standalone (LI), Caption (IG), Standalone (FB)

### LinkedIn
```
Ein Mythos, der sich hartnäckig hält: "Jede Website braucht einen
Cookie-Banner."

Stimmt nicht. Eine Website ohne Tracking, ohne Analyse-Tools, ohne
Marketing-Skripte braucht keinen Consent-Banner — weil es nichts gibt, dem
zugestimmt werden müsste.

Der Umkehrschluss überrascht viele: Ein Cookie-Banner auf einer eigentlich
schlanken Website ist oft ein Zeichen dafür, dass im Hintergrund mehr
mitläuft, als nötig wäre.

Weniger Tracking bedeutet nicht automatisch weniger Professionalität.
Oft ist das Gegenteil der Fall.

Hat Ihre Website einen Cookie-Banner — und wissen Sie, wofür genau?

#DSGVO #Sachverständige #Mythos
```

## Donnerstag — LinkedIn / Instagram / Facebook
**Topic**: Warum „ab wann lohnt sich eine neue Website" die falsche Frage ist
**Pillar**: Praktische Tipps für Einzelkämpfer (Supporting) · **Format**: Standalone (LI), Caption (IG), Standalone (FB)

### LinkedIn
```
"Ab wann lohnt sich eine neue Website?" ist die Frage, die mir am häufigsten
gestellt wird. Und es ist die falsche Frage.

Die richtige Frage lautet: "Wie viele Anfragen verliere ich gerade, ohne es
zu merken?"

Eine Website, die technisch funktioniert, aber niemanden überzeugt, zeigt
keine Fehlermeldung. Sie verliert einfach still Anfragen — an Wettbewerber,
die auf den ersten Blick vertrauenswürdiger wirken.

Das lässt sich nicht in einer Kennzahl ablesen, aber an einer einzigen
Beobachtung: Wie oft hören Sie "ich habe Sie über Empfehlung gefunden",
verglichen mit "ich habe Sie über die Website gefunden"?

Wenn die Website in dieser Antwort kaum vorkommt, lohnt sie sich vermutlich
schon länger nicht mehr in ihrer jetzigen Form.

#Sachverständige #Webdesign #Perspektive
```
